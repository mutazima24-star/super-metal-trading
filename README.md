# المعدن الفائق التجارية (Super Metal Trading)

## نظرة عامة
موقع إلكتروني لشركة المعدن الفائق التجارية، تأسست عام 2025 في جدة، تقدم خدمات الهدم والتفكيك، تجارة السكراب، وتأجير المعدات الثقيلة للقطاعات الصناعية والإنشائية في مملكة المملكة العربية السعودية.

## الخدمات
- **الهدم والتفكيك**: إتمام أعمال الهدم والتفكيك بدقة، مع فرز وإزالة المخلفات للتدوير
- **تجارة السكراب**: شراء وبيع السكراب والمعادن (حديد، نحاس، ألمنيوم، معادن متنوعة، بلاستيك، طبليات، خشب)
- **تأجير المعدات**: تأجير معدات ثقيلة (حفارات، شيولات ولودرات، بلدوزرات، بوبكاتات) لأعمال الحفر والتحميل والنقل
