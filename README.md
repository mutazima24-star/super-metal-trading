# المعدن الفائق التجارية

المصدر الكامل للتصميم الأصلي، مهيأ للبناء على Vercel باستخدام Next.js.

## التشغيل

Node.js 22.13 أو أحدث وpnpm 11:

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

ينتج البناء موقعًا ثابتًا كاملًا في `out/`، بما فيه جميع ملفات JavaScript والخطوط والصور. يبني Vercel المصدر تلقائيًا حسب `vercel.json`. لا تنسخ HTML أو أجزاء `_next` منفردة؛ تعتمد التفاعلات على ملفات البناء الكاملة والمتطابقة.

## الملفات الرئيسية

- `app/`: الصفحة العربية وتخطيطها وتنسيقها المتجاوب.
- `components/`: القائمة، تبويبات المعدات، الوثائق ونموذج الطلب.
- `lib/industrial-scenes.ts`: حركات الهدم والفرز والمعدات الأصلية باستخدام Three.js.
- `public/fonts/`: أوزان خط Tajawal الأصلي، مستضافة محليًا.
- `public/assets/`: الشعار والصور والبروفايل.

المشاهد ثلاثية الأبعاد تتطلب WebGL. عند عدم دعمه تظهر الصور البديلة ويبقى الموقع وتفاعلاته قابلين للاستخدام. يحترم الموقع إعداد تقليل الحركة ويتيح الإيقاف والإعادة.

نموذج الطلب يجهز رسالة في واتساب أو البريد؛ يراجعها الزائر ويرسلها بنفسه، ولا توجد قاعدة بيانات أو عملية إرسال تلقائية.
